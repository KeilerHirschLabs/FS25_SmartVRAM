# FS25_SmartVRAM (SVRAM)

**Status: research and development — no public mod build or release.**

FS25_SmartVRAM is an independent Farming Simulator 25 project exploring whether small, GIANTS-native texture-streaming and memory-budget adjustments can improve resource handling under real gameplay conditions.

## Intended scope

- A lightweight, **Lua-only**, fire-and-forget mod without a settings UI or manual tuning.
- No external executables, Python helper, registry edits, driver changes, background services or operating-system tweaks.
- A standalone project, separate from **FS25 Advanced Realism Suite (ARS)** and without an ARS runtime dependency.

## Current state

Earlier experimental builds under the **AutoVRAMOptimizer** name have been tested locally. Their effects have **not** been established through reproducible performance measurements. There is no verified claim of higher FPS, shorter loading times, lower VRAM usage or improved stability.

**No source code or downloadable mod is published in this repository yet.**

## Before a release

GIANTS runtime API behavior and units must be verified, changes tested in comparable gameplay scenarios, and compatibility, mod identity and distribution rights reviewed.
